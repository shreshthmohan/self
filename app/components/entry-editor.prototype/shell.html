The hydration gap in the editor

The edit page paints server HTML first and hydrates a moment later. In that window a person can type, and today React throws the typing away (#89). The question this demo answers: which way of writing the fields keeps what a person typed — the text, the caret, the checkbox — and still leaves a working editor behind?

Nothing here is timed. The form below is real server HTML that is not hydrated yet. Type into it — or press the buttons — then press Hydrate now to land the runtime by hand. The table shows what each field held before and after.
